## 🌟 Highlights & Architecture

- **Cinematic Visual Identity**: Sleek dark aesthetic with neon cyan accents, subtle glassmorphism, and atmospheric depth.
- **Three.js 3D Mesh Sculpture**: Custom wireframe geometry in the Hero with auto-pause on scroll and visibility change (`IntersectionObserver`), plus adaptive level of detail and CSS fallback.
- **Fluid & Responsive**: Hand-tuned across all device form factors from **360px mobile viewports** up to **4K ultra-wide screens** (`clamp()` typography, `scrollbar-gutter: stable`, zero horizontal overflow).
- **Mobile-Optimized Input**: Conditional custom cursor and magnetic physics that gracefully disable on touch devices (`pointer: coarse`) to conserve battery and CPU.
- **Narrative Section Flow**:
  1. **Hero** — 3D interactive sculpture, fluid headline, and dual CTAs.
  2. **About** — Narrative bio, tech philosophy, and categorized skill pills.
  3. **Selected Work** — Featured ventures (`Rathora`, `DhanurX`, `AI Video Concept`, `The Lab`) with rich modal case studies.
  4. **Creative** — Cinematic reels and visual storytelling breakdowns.
  5. **The Lab** — Ongoing technical R&D and prototypes across AI, shaders, and web experiments.
  6. **Philosophy** — Core engineering creed: *"Build. Break. Learn. Rebuild."*
  7. **Honors & Certificates** — Verified credentials and awards in AI, Startup Acceleration, and Software Engineering.
  8. **Journey** — Interactive chronological milestone timeline.
  9. **Contact** — Direct message form, platform links, and verified email integration.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed on your machine
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/sujithharshaT/portfolio-sujith.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Launch development server
npm run dev
```

### Production Build & Linting

```bash
# Run linter
npm run lint

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
